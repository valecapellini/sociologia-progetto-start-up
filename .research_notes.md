# API Research Notes

## Project Overview
- Python scraper using Playwright to scrape startup data from startup.registroimprese.it
- Files: main.py, scraper.py, exporter.py
- Scrapes Italian startup registry for region-specific startup data (e.g., Liguria)
- Exports to CSV in dati/ folder
- Uses Playwright browser automation with captcha detection and cookie management

## Site Architecture (startup.registroimprese.it)
- Built on Apache Wicket framework
- Uses Semantic UI dropdowns for form elements
- Heavy anti-bot protection: Imperva/TSPD (cookies: TSPD_101, TS014fd200, TSce795e2f027)
- CAPTCHAs triggered aggressively for automated requests
- Session managed via JSESSIONID cookies

## Wicket AJAX Endpoints Found
- Base URL pattern: `./search?{pageId}-1.0-vetrinaSearch-vetrinaSearchForm-{fieldName}`
- Checkbox startup: `startupChk-chkFld` (POST, body: `startupChk%3AchkFld=on`)
- Region selection: `regionFld-contenitore-supplierSel`
- Company name autocomplete: `denominazioneFld&query={query}` (uses Semantic UI apiSettings)
- NACE code autocomplete: `codiceAtecoFld&query={query}`
- Tag autocomplete: `hashtagFld&query={query}`

## Key Finding: No Public REST API
- The site does NOT have a public REST/JSON API
- All interactions are via Wicket form posts returning HTML/XML fragments
- The "ACCESS TO DATA" section links to dashboard and CSV downloads
- accessoallebanchedati.registroimprese.it/abdo/api is a PAID commercial API by InfoCamere

## Alternative Data Sources Explored
1. MIMIT (mimit.gov.it) - only publishes PDF quarterly reports, no CSVs
2. dati.gov.it - no specific startup innovative datasets found
3. dati.mise.gov.it - domain no longer resolves (ministry renamed to MIMIT)

## Critical Conclusions
1. The site HAS CSV open data downloads - visible in the ACCESS TO DATA menu
2. BUT all endpoints are behind Imperva TSPD bot protection
3. No public REST/JSON API exists - only Wicket form-based HTML application
4. The paid commercial API (accessoallebanchedati.registroimprese.it) provides real-time API access
5. Autocomplete endpoints (denominazioneFld, codiceAtecoFld, hashtagFld) return structured data but behind same bot protection

## Recommended Approach
Since no clean API exists, the best improvement would be:
1. Use the CSV open data download from "ACCESS TO DATA" section if it provides bulk data
2. Keep the Playwright scraper but make it more resilient (it's the only viable free approach)
3. OR: Try using the Wicket AJAX endpoints with proper session/cookie management after manual CAPTCHA solve
4. The autocomplete endpoints might provide company name → ID mappings that could be useful
